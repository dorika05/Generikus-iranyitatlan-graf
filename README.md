# Generikus-iranyitatlan-graf

## Rövid leírás
A generikus_graf.exe program segítségével irányítatlan generikus gráfokat tudunk kezelni. A
program képes egy mátrixszal leírt állományból a gráfot felépíteni, majd azt bármelyik
csúcsából bejárni, szélességi bejárást végezve. A szélességi bejárásokat elvégezve el tudja
dönteni, hogy a gráf összefüggő-e. Több komponens esetén kilistázza, hogy mely csúcsok
tartoznak egy komponensbe.

## Használat
A projekt Code::Blocks-ban megnyitható (.cbp fájl).

## Dokumentáció
A részletes dokumentáció a `dokumentacio_iranyitatlan_graf.pdf` fájlban található.
